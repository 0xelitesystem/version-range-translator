Version Range Translator

Type one version range. See how npm, Cargo, Composer, PEP 440 and RubyGems each read that exact string, as plain comparators tested against versions you list.

The same string, five readings. ~1.2 stops below 1.3 in npm and Cargo but below 2.0 in Composer. ~>1.2 stops below 1.3 in npm but below 2.0 in RubyGems. A bare 1.2 is 1.2.x in npm, below 2.0.0 in Cargo, exactly 1.2.0 in Composer and RubyGems, and not a valid specifier in PEP 440. Each ecosystem is following its own published or implemented grammar. This page runs a port of each one, offline.

PEP 440 notes: already-installed pre-releases are not modelled. The --pre box above models an explicit user request. Composer notes: this page models the default minimum-stability, explicit @ stability flags, and the flag Composer infers when a root requirement names a pre-release in a single-token constraint (^1.2.3-beta.2 admits beta and above). It reads the range as your own composer.json require; a dependency's requirements get no inferred flag.
